01. 검수 규격

자동 규격은 앞면(없으면 뒷면)의 크기에서 양쪽 도련을 뺍니다. 도련 없는 원본은 0mm로 설정하세요.

같은 축척으로 원본을 비교합니다. 안내선은 검수용이며 원본 변경이나 출력용 PDF 생성은 하지 않습니다. 실제 양면 급지 방향과 문자 여백은 직접 확인하세요.

03. 원본 파일

PDF, JPG, PNG, WebP · 파일당 100MB 이하. 서버 업로드 없이 현재 브라우저에서 확인합니다.

이미지 크기는 입력 DPI 기준이며 PDF는 페이지 표시 영역 크기를 사용합니다.
