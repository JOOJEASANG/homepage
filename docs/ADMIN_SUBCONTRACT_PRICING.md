# 관리자 하청업체 견적 계산

- 대상: 관리자 계정(`users/{uid}.role === 'admin'`)
- 페이지: `quote-book.html`, `quote-print.html`
- 동작: 관리자 계산 모드에서 `하청업체 20% 할인 적용`을 체크하면 현재 전체 견적의 80% 금액을 별도로 표시합니다.
- 고객 견적의 접수/저장 금액에는 반영하지 않습니다.
- 관리자 계산 모드에서는 실수 방지를 위해 고객 견적 접수 버튼을 비활성화합니다.

## A5 책자 정책

A5 70%는 내지 인쇄비에만 적용합니다. 표지, 간지, 제본, 오시, 디자인비에는 A5 할인율을 적용하지 않습니다.
