# 마이페이지 견적서 단가·금액 표시 보정

## 원인

- 책자 견적은 가격이 포함된 `items`보다 사양만 포함된 `formData`를 먼저 읽어 품목 단가가 0원으로 표시되었습니다.
- 디지털인쇄는 저장된 품목 합계(`itemTotal`)와 사이즈·양면·오시가 반영된 합계를 사용하지 못하는 구형 데이터가 있었습니다.

## 보정 내용

- `formData`, `items`, `breakdownData`를 함께 읽어 품목별 수량·단가·금액을 복원합니다.
- 품목 합계가 있으면 수량으로 나누어 실제 표시 단가를 계산합니다.
- 구형 단일 품목 데이터는 전체 견적 합계에서 금액을 복원합니다.
- `finalPrice`, `totalPrice`, `vat`, `vatPrice` 등 서로 다른 저장 필드도 정규화합니다.

## 변경 범위

- 기존 접수 및 계산 로직은 변경하지 않습니다.
- 마이페이지 견적서 출력 직전에 표시용 데이터만 보정합니다.
